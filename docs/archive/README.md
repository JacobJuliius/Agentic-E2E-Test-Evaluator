# Historical archive

This directory contains material that is useful for research traceability but
is not part of the active evaluator:

- superseded V4/V5 README snapshots;
- earlier prompt text files and one-off model checks;
- historical evaluation/sample CSV files;
- legacy patch sets under `patches/`;
- the superseded dynamic dependency list;
- an earlier mutation-plan instance and standalone test runner.

Use the repository-level `README.md` and the active documents one directory
above for current commands and architecture. Archived commands and paths may no
longer match the current tree.
